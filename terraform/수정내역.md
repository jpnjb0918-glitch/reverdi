## 🔴 추가로 고친 것 — `versions.tf`

### 무엇이 문제였나

```hcl
bucket = "reverdi-tfstate-<계정번호(재윤씨가쓸 것)>
                                              ↑ 닫는 따옴표 없음
```

제 안내 문서의 `<계정번호>` 자리 표시자가 그대로 남았고,
**따옴표가 안 닫혀 `terraform init` 자체가 실패**합니다.

### 어떻게 고쳤나

**백엔드 블록을 주석 처리**했습니다.

```hcl
# backend "s3" {
#   bucket         = "reverdi-tfstate-611669940814"
#   ...
# }
```

**이유** — S3 버킷과 DynamoDB 테이블이 **아직 없습니다.**
있지도 않은 백엔드를 가리키면 `init` 이 실패합니다.

주석에 **켜는 절차**를 적어뒀습니다.

```
① S3 버킷 · DynamoDB 생성 (명령 3줄)
② 주석 풀기
③ terraform init -migrate-state
```

```bash
cd terraform
```

**상태 파일은 로컬에 생깁니다.** `.gitignore` 로 막혀 있어 git 에는 안 올라갑니다.

혼자 `plan` 만 돌릴 거면 이대로 충분합니다.

## 백엔드를 켜야 할 때

**둘 이상이 `apply` 를 하게 되면** 그때 켭니다.

```bash
ACCOUNT=$(aws sts get-caller-identity --query Account --output text)

aws s3api create-bucket --bucket reverdi-tfstate-$ACCOUNT \
  --region ap-northeast-2 \
  --create-bucket-configuration LocationConstraint=ap-northeast-2

aws s3api put-bucket-versioning --bucket reverdi-tfstate-$ACCOUNT \
  --versioning-configuration Status=Enabled

aws dynamodb create-table --table-name reverdi-tflock \
  --attribute-definitions AttributeName=LockID,AttributeType=S \
  --key-schema AttributeName=LockID,KeyType=HASH \
  --billing-mode PAY_PER_REQUEST --region ap-northeast-2
```

그다음 `versions.tf` 주석을 풀고,

```bash
terraform init -migrate-state
```

로컬 상태가 S3 로 옮겨집니다.
